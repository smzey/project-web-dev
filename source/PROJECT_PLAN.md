# แผนโปรเจกต์ — ระบบสมัครเข้าร่วมกิจกรรม

> ใช้คู่กับ `PROJECT_RULES.md` — ถ้ามีอะไรขัดกัน ให้ยึด requirement ของอาจารย์เป็นหลัก

## แนวคิด

ทำเว็บ **ระบบสมัครเข้าร่วมกิจกรรม** ด้วย Laravel + Blade
ใช้เว็บที่ทำพร้อมอาจารย์ในคาบ (`my-db`: Product – Shop – Category – User) เป็น **reference**
ทำโครงสร้างและวิธีเขียนให้ **ใกล้เคียงกับเว็บในคาบ** และต้อง **ตรงตาม requirement ของโปรเจกต์ครบทุกข้อ**

## ใช้เว็บในคาบเป็น reference อย่างไร

- เปลี่ยนเนื้อเรื่องจาก "สินค้า–ร้านค้า–หมวดหมู่" เป็นเรื่อง "กิจกรรม" เช่น กิจกรรม, หมวดหมู่กิจกรรม, ผู้จัด, การสมัคร
- ใช้รูปแบบเดียวกับในคาบ เช่น model + relationship, CRUD, search/pagination, flash message, policy + role, try/catch
- รายละเอียด (model, ตาราง, หน้าเว็บ) ค่อยตกลงกันในกลุ่มระหว่างทำ

## สิ่งที่ต้องมีให้ครบ (ตาม requirement)

- [ ] Custom model อย่างน้อย 3 ตัว (ไม่นับ User) และมี relationship กัน
- [ ] CRUD ครบอย่างน้อย 3 model
- [ ] แจ้งเตือนผ่าน session ทุกการจัดการข้อมูล รวมถึงกรณี error
- [ ] Login/Logout, 2 role, protected routes และ public routes (นอกจากหน้า login)
- [ ] CSS
- [ ] PHP library ภายนอก 1 ตัวที่ไม่ได้สอนในคาบ

## สิ่งที่ต้องต่างจากเว็บในคาบ

- **ต้องเป็นโปรเจกต์ใหม่** — ใช้เว็บในคาบเป็นแบบอย่างได้ แต่ห้ามเอาโปรเจกต์จากแล็บมาแก้ต่อ
- **ต้องมี public routes** — ในคาบทุกหน้าต้อง login แต่โปรเจกต์ต้องมีหน้าที่เข้าได้โดยไม่ login
- **ต้องมี PHP library ภายนอก** — ในคาบไม่มีส่วนนี้
